{%- comment -%} Schema.org JSON-LD. Why this exists: jekyll-seo-tag only emits a thin WebPage/Person stub. Search engines (and increasingly AI answer engines) build an *entity* for a researcher from an explicit Person node with `sameAs` links to Scholar / ORCID / GitHub, plus ScholarlyArticle nodes for the publications. That is what makes a knowledge-panel-style result and a citable answer possible.
