{%- comment -%} Inline SVG icons. Usage: {% include icon.html name="github" %} {% include icon.html name="star" class="panel-icon" px="18" %} NOTE: the size parameter is called `px`, not `size`. On a Liquid hash, `include.size` resolves to the NUMBER OF PARAMETERS passed, not to a parameter named "size" — which silently renders every icon at 1x1. Why inline rather than an icon font: the whole site used 17 icons, which cost two stylesheets (Font Awesome, Academicons) plus several hundred KB of webfonts, all on third-party origins. Those stylesheets loaded asynchronously, so every icon popped in after first paint. Inline SVG is part of the HTML, renders immediately, costs nothing extra, and lets the brand marks carry their own colours. UI icons are 24x24 stroke icons (Lucide-style geometry).
